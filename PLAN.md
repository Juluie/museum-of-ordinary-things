## Архитектура

```
GitHub (этот репозиторий) ─ код, миграции, функции, тесты, документация
   │ push в main
   ▼
Cloudflare Pages ─ собирает сайт (npm run build → dist), отдаёт статические файлы
   │ браузер посетителя
   ▼
Supabase ─ Postgres (экспонаты), приватный Storage (фото), Auth (вход хранителя),
           Edge Functions (submit-exhibit, public-exhibits, admin-exhibits)
```

Браузер не обращается к таблицам напрямую: все чтения и записи идут через Edge Functions с проверками на сервере. Фото лежат в приватном бакете, наружу отдаются только временные ссылки на опубликованные экспонаты.

## Внешние зависимости

| Сервис | Зачем | Тариф | Кто подключает |
|---|---|---|---|
| GitHub | хранение кода, CI | бесплатный | после твоего подтверждения |
| Cloudflare Pages | хостинг сайта | бесплатный | ты входишь в аккаунт, я даю шаги |
| Cloudflare Turnstile | защита формы от ботов | бесплатный | ты |
| Supabase | БД, фото, вход, функции | бесплатный (Free) | ты входишь, команды — в docs/SETUP_SUPABASE.md |

Платные тарифы не подключаются.

## Решения по умолчанию

- Режим по умолчанию — `demo`. Live включается только явной переменной `VITE_APP_MODE=live`; неполные настройки → страница ошибки, а не тихий demo.
- Приём выключен по умолчанию на сервере (`SUBMISSIONS_ENABLED`) и на сайте (`VITE_SUBMISSIONS_ENABLED`).
- Лимиты: 3 отправки в час и 10 в сутки с одного адреса, 100 в сутки всего.
- Фото: до 10 МБ на входе, в браузере уменьшается до 1600 px по длинной стороне; на сервере — повторная проверка и пересохранение в JPEG.
- Временные ссылки на фото: 1 час для посетителей, 10 минут для админки.
- Номер экспоната выдаётся при первом одобрении и никогда не меняется.
