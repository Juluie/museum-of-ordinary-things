## Пробная отправка (временно `SUBMISSIONS_ENABLED=true` + `VITE_SUBMISSIONS_ENABLED=true`)
- [ ] Фото с телефона с геолокацией → отправка → «Твоя вещь отправлена»
- [ ] Вещь **не видна** на сайте до одобрения; прямой адрес `/exhibit/<id>` → «не найден»
- [ ] В админке видна, фото открывается
- [ ] Скачанное из админки фото без EXIF/GPS (проверить, например, `exiftool`)
- [ ] Одобрение → появился номер, вещь открывается по ссылке и через «Следующая вещь»
- [ ] Ссылка «Поделиться» открывается в другом браузере
- [ ] Снятие с публикации → ссылка показывает «не найден», старая ссылка на фото перестала работать
- [ ] Отклонение второй тестовой вещи → фото исчезло из Storage
- [ ] 4-я отправка за час с одного адреса → понятное сообщение о лимите
- [ ] Отключённый интернет при отправке → ошибка, текст на месте
- [ ] Двойной клик «Отправить» → одна запись
- [ ] Тестовые записи удалены
- [ ] Проверить, что `cf-connecting-ip` нельзя подменить: отправка с заголовком `cf-connecting-ip: 1.2.3.4` из curl не обходит лимит
