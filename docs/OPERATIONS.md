# Эксплуатация

## Модерация

1. Открой `/admin/login`, войди.
2. Вкладка **На проверке** — новые вещи, самые старые сверху.
3. Действия:
   - **Одобрить** — экспонат получает постоянный номер и появляется на сайте;
   - **Отклонить** — фото сразу удаляется, текстовая запись остаётся во вкладке «Отклонено»;
   - **Снять с публикации** — экспонат возвращается в «На проверке», номер сохраняется, старые ссылки на фото перестают работать;
   - **Удалить навсегда** — запись и фото удаляются без возможности восстановления (кроме резервных копий).
4. Что не публиковать: документы, адреса, телефоны, лица посторонних, чужие личные данные, оскорбления, реклама.

Срок проверки на сайте не обещается.

## Сроки хранения

| Данные | Срок | Как обеспечивается |
|---|---|---|
| Опубликованные экспонаты | пока существует музей или до просьбы удалить | вручную |
| Фото отклонённых | удаляется сразу | автоматически при отклонении |
| Текст отклонённых | `<ЗАПОЛНИТЬ: срок>` — затем удалить | вручную, запрос ниже |
| Хеши адресов (лимиты) | 2 суток | pg_cron, docs/SETUP_SUPABASE.md §8 |
| Резервные копии | `<ЗАПОЛНИТЬ: срок>` | зависит от тарифа Supabase |

Удалить отклонённые старше N дней (SQL Editor; у них уже нет фото):

```sql
delete from public.exhibits
where status = 'rejected' and created_at < now() - interval '30 days';
```

Сроки нужно вписать и на страницу «Приватность» (`src/pages/PrivacyPage.tsx`).

## Очистка orphan-файлов

Файл без записи может остаться, если функция упала между загрузкой и записью (функция пытается удалить его сама). Найти такие файлы:

```sql
select o.name, o.created_at
from storage.objects o
left join public.exhibits e on e.image_path = o.name
where o.bucket_id = 'exhibit-images'
  and e.id is null
  and o.created_at < now() - interval '1 day';
```

Удалять через панель **Storage → exhibit-images** (не через `delete from storage.objects` — так файл останется в хранилище).

## Очистка записей лимитов

Автоматически через pg_cron. Вручную:

```sql
select public.cleanup_submission_rate_limits();
```

## Контроль объёма Storage

```sql
select count(*) as files,
       pg_size_pretty(sum((metadata->>'size')::bigint)) as total
from storage.objects where bucket_id = 'exhibit-images';
```

Одно фото после обработки — обычно 150–600 КБ. При 100 отправках в сутки максимум — около 60 МБ в день. Если объём приближается к лимиту тарифа, уменьши `SUBMIT_LIMIT_GLOBAL_PER_DAY` или закрой приём.

## Резервное копирование и восстановление

- На бесплатном тарифе Supabase автоматические бэкапы ограничены — проверь актуальные условия в панели (**Database → Backups**).
- Ручной бэкап базы (в твоём терминале, файл **не класть в репозиторий** — `*.dump` и `backups/` в `.gitignore`):

```bash
npx supabase db dump --data-only -f backups/data-$(date +%F).sql
npx supabase db dump -f backups/schema-$(date +%F).sql
```

- Фото: скачать содержимое бакета через панель **Storage → exhibit-images**.
- Восстановление: новая база → `npx supabase db push` (схема) → импорт данных через `psql` → загрузка файлов в бакет по тем же путям.
- Бэкапы содержат личные истории — храни их зашифрованными и удаляй по сроку.

## Удаление по обращению

1. Человек пишет на `<ЗАПОЛНИТЬ: email для обращений>` со ссылкой на экспонат или номером.
2. Убедись, что просьба правдоподобна (например, ответ с того же адреса, детали истории).
3. Найди запись: `select id, title, status from public.exhibits where inventory_number = 42;`
4. В админке — **Удалить навсегда**: удаляются и запись, и фото.
5. Ответь, что удалено. Предупреди, что из резервных копий запись исчезнет по истечении их срока, а уже скачанные кем-то копии удалить нельзя.

## Ограничения бесплатных тарифов

Проверяй актуальные цифры на сайтах сервисов — они меняются.

- **Supabase Free:** проект засыпает после недели без активности (нужно «разбудить» в панели); ограничены объём базы, Storage, трафик и число вызовов функций; Edge Functions — лимит памяти и CPU-времени на запрос ([Supabase: лимиты функций](https://supabase.com/docs/guides/functions/limits)).
- **Cloudflare Pages Free:** ограничено число сборок в месяц.
- **Turnstile:** бесплатен.

## Закрыть приём

```bash
npx supabase secrets set SUBMISSIONS_ENABLED=false
```

Действует сразу. Чтобы скрыть и форму на сайте — `VITE_SUBMISSIONS_ENABLED=false` в Cloudflare Pages и пересборка.
